Changelog

Every change to akashvani, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

Unreleased

  • Every corner is rounded: the website's callouts.
  • A logo and a shloka at the top of the README and the website: every Vayu tool has them now.

v0.2.02026-11-02release ↗

  • Renamed from suchana to akashvani (आकाशवाणी, the voice from the sky). The repository moved to github.com/Theyashsawarkar/akashvani (the old address redirects); kosha update moves an install over by itself; open it with vyom akashvani.
  • Screenshots in the README and on the website.

v0.1.42026-10-21release ↗

  • A website (GitHub Pages, https://theyashsawarkar.github.io/suchana/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.32026-10-21release ↗

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.22026-10-19release ↗

  • Opens at Vyom's shared panel size (Vyom 0.2.5) like every other tool: its own width/height are gone.

v0.1.12026-10-19release ↗

  • Keys are spelled out (Ctrl+Enter, Shift+Enter, Backspace) instead of symbols (⌃↵, ⇧↵, ⌫) in the footer and on rows and buttons.

v0.1.02026-10-19release ↗

  • First release, as its own repository: notifications. Replaces notification-history.py in Vayu.
  • What's on screen now, with the actions it offers (run them, or dismiss it).
  • The history, grouped by app, newest first, with each app's icon; urgent ones flagged.
  • The preview shows the whole message.
  • A do not disturb switch (mako's do-not-disturb mode, or your own commands).
